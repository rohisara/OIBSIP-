# Personal Portfolio

Features:
- Responsive layout and mobile navigation
- Dark/light theme toggle (saved in browser)
- Animated typing headline
- Scroll reveal and reading progress bar
- Project category filters
- Project detail pop-up windows
- Copy-email button and back-to-top control

## Run in Windows PowerShell
Open PowerShell in this folder and run:

```powershell
py -m http.server 5500
```

Open http://localhost:5500 in your browser. Stop with Ctrl+C.

## Customize before publishing
- Replace `Your Name` and `you@example.com`.
- Update LinkedIn and GitHub links.
- Edit the project descriptions and skills so they accurately reflect your work.
- Add your own photo if desired. The hero currently uses a CSS code-card illustration.
- Update project details in `script.js` if you change the projects.

No packages or build tools are required. Google Fonts are optional.
